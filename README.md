# ヒット&ブロー オンライン対戦

静的HTMLだけで動作するヒット&ブロー(2人対戦)です。サーバー不要で、GitHub Pagesで無料公開できます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | **通常版**。6桁のルームコードで接続。通信にはPeerJS(WebRTC)を使用 |
| `manual.html` | **手動接続版(予備)**。PeerJSも外部サーバーも使わず、招待コード/返信コードをコピペして接続 |
| `.nojekyll` | GitHub PagesでJekyllの処理を無効にする空ファイル(なくても動作します) |

通常版が繋がらない日(PeerJSの無料サーバーが落ちている等)は、`manual.html` を使ってください。

## 公開方法(GitHub Pages / Deploy from a branch)

1. GitHubで新しいリポジトリを作成する(Publicにする)。
2. このフォルダの**中身**を、`main` ブランチ直下へアップロードする。`index.html` が直下にあることを確認する。
3. `Settings` → `Pages` → `Build and deployment` → `Source` で **Deploy from a branch** を選ぶ。
4. `Branch` を `main`、フォルダを `/ (root)` にして `Save` を押す。
5. 数分待つと、`https://ユーザー名.github.io/リポジトリ名/` で公開される。そのURLを友達に送る。

うまくいかない場合:
- 404になる → `index.html` が `main` 直下にあるか確認してください。
- 反映されない → 数分待ち、ブラウザを強制再読み込み(キャッシュなしの更新)してください。
- 無料プランでは、リポジトリをPublicにする必要があります。

## 遊び方(通常版)

1. **ホスト**が「ルームを作る」を押す。6桁のルームコードが表示される。
2. ルームコードを友達に伝える。
3. **ゲスト**がルームコードを入力して「入室する」を押す。
4. ホストが形式(カラー4色/数字4桁)や手数制限を選んで開始する。
5. 相手の答えをHit & Blowで推理して、先に当てた方の勝ち。

ホーム画面の最上部に、接続診断(ライブラリ/接続サーバーが OK か NG か)が表示されます。NGの場合は `manual.html` を使ってください。

## 注意

- ホストまたはゲストがブラウザを閉じると、対戦は終了します。
- 会社や学校のネットワークなど、環境によってはWebRTCの直接接続が成立しない場合があります。
- 答えは通信に載せず、対戦終了時にだけ相手へ公開します。
