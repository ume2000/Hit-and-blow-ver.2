# ヒット&ブロー オンライン対戦

静的HTMLだけで動作するヒット&ブロー(2人対戦)です。自前のサーバーは不要で、GitHub Pagesで無料公開できます。

## ファイル構成(繋がり方が3種類)

| ファイル | 繋がり方 | 備考 |
| --- | --- | --- |
| `index.html` | **通常版**。6桁のルームコードで接続。接続の仲介に無料の公開サービス **ntfy.sh** を使い、対戦はブラウザ同士が直接通信(WebRTC) | 最初に試す |
| `peerjs.html` | 6桁のルームコードで接続。仲介にPeerJSの無料サーバーを使う | 通常版が繋がらない時 |
| `manual.html` | 招待コード/返信コードをコピペして接続。外部の仲介サービスを使わない | 最後の手段(スマホでは切れやすい) |

各ページ下部のリンクで行き来できます。

## 公開方法(GitHub Pages / Deploy from a branch)

1. GitHubで新しいリポジトリを作成する(Publicにする)。
2. このフォルダの**中身**を、`main` ブランチ直下へアップロードする。
3. `Settings` → `Pages` → `Build and deployment` → `Source` で **Deploy from a branch** を選ぶ。
4. `Branch` を `main`、フォルダを `/ (root)` にして `Save` を押す。
5. 数分待つと、`https://ユーザー名.github.io/リポジトリ名/` で公開される。そのURLを友達に送る。

反映されない時は、数分待ってから、ブラウザを強制再読み込みしてください。

## 遊び方(通常版)

1. **ホスト**が「ルームを作る」を押す。6桁のルームコードが表示される。
2. ルームコードを友達に伝える(「コードを共有・コピー」ボタンが使えます)。
3. **ゲスト**がルームコードを入力して「入室する」を押す。
4. ホストが形式や手数制限を選んで開始する。
5. 相手の答えをHit & Blowで推理して、先に当てた方の勝ち。

ホーム画面の最上部に接続診断(WebRTC / 仲介サービス)が出ます。NGの場合は別の版を試してください。

## 注意

- ホストまたはゲストがブラウザを閉じると、対戦は終了します。
- ntfy.shは誰でも使える公開サービスです。接続の受け渡し(接続情報)が、短時間そのサービスを通ります。ゲームの内容は通りません。
- 会社や学校のネットワークなど、環境によってはWebRTCの直接接続が成立しない場合があります。
- 答えは通信に載せず、対戦終了時にだけ相手へ公開します。
